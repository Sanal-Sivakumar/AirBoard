Features

AirBoard runs a localized TCP loopback service directly on Android linked to the native background service. It bypasses OS clipboard reading bans automatically, keeping your connection alive and synchronizing your clips even when the app is completely swiped away.

Installation Guide

Sideloading & Security Bypass

Since AirBoard is in pre-release beta and not distributed through Apple's App Store, you need to follow these steps to bypass macOS Gatekeeper or install the .ipa package on iOS & Apple Silicon Macs.

🍎 macOS Installation & Sideloading

1. Bypass Gatekeeper (Native macOS App)

Because the desktop app is unsigned, macOS Gatekeeper will block execution when first opened. You must clear the quarantine attributes:

  1. Extract the downloaded airboard-macos.zip bundle.
  2. Move AirBoard.app into your /Applications directory.
  3. Open Terminal.app (located in Applications > Utilities).
  4. Run the following command to clear quarantine flags: 
    xattr -cr /Applications/AirBoard.app
  5. Double-click the app to launch it instantly!
  6. Alternative: Right-click the app, choose Open, and click Open on the verification popup. Or go to System Settings > Privacy & Security and click Open Anyway under the blocked app list.

2. Run iOS App on macOS (Apple Silicon only)

You can run the universal iOS app layout natively on Apple Silicon Macs (M1/M2/M3/M4 systems) using sideload tools:

  1. Download the AirBoard IPA file onto your Mac.
  2. Download and install PlayCover (an open-source tool for running iOS apps natively on macOS with keyboard/mouse support).
  3. Open PlayCover and drag the downloaded .ipa file directly into the app catalog window to install and sign it locally.
  4. Double-click the AirBoard icon inside PlayCover to run it.
  5. Alternative (Sideloadly): Open Sideloadly on your Mac, choose **Apple Silicon Mac** under devices, drag the IPA, enter your Apple ID, and click **Start** to sign and install it.

📱 iOS Sideloading (iPhone & iPad)

Method 1: Sideloadly (Easiest)

Sideloadly is a free desktop program (Windows/macOS) that installs apps using your Apple ID. It is highly reliable.

  1. Download and install Sideloadly on your computer.
  2. Download the AirBoard IPA file above onto your computer.
  3. Connect your device (iPhone/iPad) to your computer using a USB cable.
  4. Open Sideloadly, select your device, and enter your Apple ID.
  5. Drag and drop the downloaded .ipa file into Sideloadly.
  6. Click Start and enter your Apple ID password if prompted (sent securely to Apple).
  7. On your device, open Settings > General > VPN & Device Management, select your Apple ID, and tap Trust.

Method 2: AltStore & TrollStore

If you already use a mobile installer directly on your device:

  • AltStore: Download the .ipa directly on your device, open AltStore, tap the "+" button on the My Apps tab, and select the AirBoard file.
  • TrollStore: Works permanently if your device runs a compatible iOS version (iOS 14.0 - 16.6.1). Refer to the TrollStore Guide and open the .ipa using TrollStore to install it permanently without the 7-day developer expiration.
Frequently Asked Questions

Have Questions? We Have Answers.

No, never. AirBoard is built on a strict zero-trust, offline-first peer-to-peer (P2P) architecture. Your clipboard content stays entirely within your local network (LAN) and is sent directly from one device to another. There are no registration forms, no cloud servers, and no third-party tracking.

Clipboard synchronization is virtually instantaneous, taking less than 50 milliseconds. Because data transfers directly between devices over local sockets rather than routing through the internet to a remote server, there is zero lag or latency.

All communications are encrypted end-to-end. Device identity key pairs are generated locally using Ed25519 signing. Every sync session is established through an ephemeral X25519 Diffie-Hellman cryptographic handshake, and data packets are secured using ChaCha20-Poly1305 symmetric encryption. Only paired devices with matching keys can decrypt your data.

AirBoard is highly optimized for power efficiency. On Android, it uses a lightweight local TCP loopback service, while on iOS/macOS, it employs standard low-power OS timers and passive socket listening. It remains idle until a local copy event is triggered, ensuring near-zero battery drain.
